# Calculadora em JavaScript

Este projeto é uma calculadora desenvolvida como trabalho escolar pedido pelo professor **Edson Protti**. O principal objetivo da atividade foi praticar conceitos de **programação orientada a objetos** usando JavaScript.

## Objetivo do projeto

O projeto foi criado para aplicar na prática a separação de responsabilidades dentro do código. A calculadora possui uma parte responsável pela lógica dos cálculos e outra parte responsável pela interação com a tela.

Com esse trabalho, pude desenvolver melhor minha lógica de programação e também aprender coisas novas no JavaScript, principalmente sobre classes, métodos, eventos e manipulação do HTML pelo DOM.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como funciona

A calculadora permite realizar operações matemáticas básicas diretamente pela interface da página. Os botões adicionam números, escolhem operações e exibem o resultado no display.

Funcionalidades presentes:

- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem
- Uso de vírgula decimal
- Limpar todos os valores
- Exibição do resultado na tela

## Programação orientada a objetos

O código JavaScript foi organizado usando classes:

- `Calculadora`: responsável por guardar os números digitados, a operação escolhida e realizar os cálculos.
- `CalculadoraUI`: responsável por conectar os botões da tela com a classe `Calculadora`, atualizando o display conforme o usuário interage com a calculadora.

Essa organização ajudou a entender melhor como a programação orientada a objetos pode deixar o código mais dividido, organizado e fácil de compreender.

## Arquivos do projeto

- `index.html`: estrutura da calculadora.
- `style.css`: estilização visual da página e dos botões.
- `script.js`: lógica da calculadora e interação com a interface.
- `img/delete.png`: imagem usada no botão de apagar.
